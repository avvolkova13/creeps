## Реализовано

- Главная: херо с движущимися иллюстративными карточками, конвертер сразу под ним, блок категорий, витрина, независимые формы баланса сайта и прямого Steam, четыре FAQ из согласованной структуры.
- Каталог `/catalog`: поиск, категория, диапазон цен с рублёвым эквивалентом, фильтр состояния при наличии таких данных, сброс. На mobile панель раскрывается, выбранные параметры видны в отдельной сводке.
- Товар `/catalog/[id]`: компонент изображения, названия, категории, описания, состояния/float, обеих цен и способов оплаты. Подготовлен быстрый просмотр из витрины через native dialog. Без данных эти заполненные состояния не показаны как настоящие товары.
- Общая навигация и подвал с support@shop-skin.com. Вход и корзина открывают объяснение недоступности. Кабинет, сессия, покупки и оплата не имитируются.
- По прямому исправлению пользователя палитра заменена на тёмную из вступительных экранов https://ten.375.studio/en: сине-серый зернистый фон, ледяной голубой текст, тонкие светлые контуры, тёмные подложки 86%. Оранжевый акцент убран. Локальные Unbounded для широких жирных заголовков и Manrope для текста заменили системный шрифт; кириллица подтверждена метаданными, лицензии OFL сохранены в public/fonts/. Это похожие шрифты, не оригинальный файл TEN.
- Конвертер работает в обе стороны, сохраняет ручной ввод, принимает точку/запятую, нейтрально обрабатывает очистку и показывает ошибку неверного ввода/переполнения. Два знака — справочное отображение, не правило расчёта платежа.
- Пополнение Creeps показывает справочную сумму в рублях. Прямое Steam имеет отдельные сумму в рублях и Steam ID. Поля не связаны с балансом/корзиной; без проверки аккаунта и провайдера отправка отключена. Пресеты сумм не придуманы.
- Внутренняя модель товаров отделена от источника. `getCatalog()` возвращает `unavailable`; отдельные компоненты различают loading/error/empty. `notFound()` товара вызывается только при успешных данных и отсутствующем ID, не при недоступности источника.
- Новые зависимости не добавлены. Git/ветки/история не менялись, commit/push/deploy не выполнялись.
