# Публикация Creeps на GitHub Pages

Репозиторий: https://github.com/avvolkova13/creeps (публичный).
Рабочий адрес: https://avvolkova13.github.io/creeps/.

## Сборка

Node.js 24, зависимости устанавливаются по lockfile:

```sh
npm ci
npm run lint
npm test
npm run typecheck
npm run build:pages
npm run check:pages
```

Результат — каталог `out/`. Скрипт получает имя репозитория из `GITHUB_REPOSITORY`; локально используется `/creeps`. `NEXT_PUBLIC_BASE_PATH` позволяет явно задать другой префикс. Все 68 страниц товаров создаются при сборке; каталог читает фильтр категории в браузере. Изображения, шрифты и текстура локальные, пути учитывают префикс проекта. Сервер Next.js для этой публикации не нужен.

`check:pages` проверяет наличие главной, каталога, 404 и каждой страницы товара, а также локальные ссылки и ресурсы HTML/CSS. Импорт с внешних сайтов не запускается в CI: сборка использует сохранённый снимок и не зависит от доступности SkinSwap/SkinBaron.

## Автоматическая публикация

В Settings → Pages → Build and deployment уже выбран **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет pull request в `main`; push в `main` и ручной запуск дополнительно публикуют проверенный артефакт. Задание публикации получает только `pages: write` и `id-token: write`; секреты аккаунта в workflow не нужны.

После первого push проверить оба задания в Actions, затем главную, переход в категорию, прямой адрес товара и его перезагрузку на публичном сайте. До успешного удалённого запуска настройка не считается проверенным деплоем. Для возврата к прошлой версии создать revert-коммит в `main`: он запустит тот же процесс публикации.

## Обновление товаров и ограничения

Обновление снимка выполняется отдельно: `npm run import:catalog`, проверка результата, тесты и коммит. Новый push публикует обновлённый каталог.

GitHub Pages обслуживает статические файлы. Steam-вход, баланс, платежи, выдача и закрытый API требуют отдельного доверенного backend. Эти интеграции пока недоступны; статическая публикация не делает их рабочими. Секреты запрещено добавлять в репозиторий, `public/` или `NEXT_PUBLIC_*`.
