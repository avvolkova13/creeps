# Публикация Creeps

Публичный репозиторий: https://github.com/avvolkova13/creeps . Ранее опубликованная статическая версия: https://avvolkova13.github.io/creeps/ , коммит 5ceda0b, успешный запуск Actions 34343832638. Серверная версия подготовлена к отправке в main 2026-09-11 по запросу пользователя. Публикация приложения ожидает адреса Node.js-хостинга с постоянным диском; текущая страница GitHub Pages остаётся прежней до настройки CREEPS_APP_URL.

## Серверная версия

Вход Steam, кабинет и корзина требуют Node.js 24. GitHub Pages не запускает серверные процессы. `npm start` теперь поднимает Next и API на одном порту; прямой `next start` поднимет только интерфейс.

Локально:

```sh
npm ci
npm run lint
npm test
npm run typecheck
npm run build
npm start -- --port 3100
```

Настройки `.env.example`:

- `APP_ORIGIN`: точный публичный HTTPS-origin без завершающего слеша. Используется для callback Steam и проверки Origin. Нельзя определять его по непроверенному Host или X-Forwarded-Host.
- `HOST`: 127.0.0.1 локально; 0.0.0.0 за настроенным HTTPS-прокси. Для публичного listener APP_ORIGIN обязателен.
- `PORT`: 3100 по умолчанию.
- `DATABASE_PATH`: файл SQLite на постоянном диске. `.data/` и `*.sqlite*` исключены из Git. База содержит закрытые профили, сессии и trade-URL.

Запускать один экземпляр приложения. Для горизонтального масштабирования потребуется общий store и ограничитель запросов. HTTPS-прокси должен обслуживать весь origin, включая `/api/`; кэширование API запрещено. Секреты не передавать в NEXT_PUBLIC_*.

Подготовлен Dockerfile с непривилегированным пользователем и `/data` для постоянного тома. Образ в этой среде не собирался: Docker отсутствует. Обязательная проверка после развёртывания — `/api/health`, вход/отмена/выход Steam, сохранение trade-URL и корзины после перезапуска контейнера. SQLite резервировать штатным online backup или при остановленном приложении, не копировать один основной файл во время WAL-записи.

## GitHub Actions и Pages

Workflow всегда выполняет npm ci, lint, тесты, typecheck и обычную Next-сборку. Пока `CREEPS_APP_URL` не задан в repository Variables, публикация Pages пропускается, текущий опубликованный сайт сохраняется.

После запуска настоящего Node-приложения установить `CREEPS_APP_URL` в его HTTPS-origin. Тогда `npm run build:pages` создаёт страницы перенаправления для главной, кабинета, каталога и 68 товаров. `npm run check:pages` проверяет 71 переход; поиск и hash сохраняются JavaScript-переходом. Pages остаётся входной ссылкой, функционал работает на серверном домене. Пустой или неверный адрес не создаёт артефакт с неработающими API-ссылками. Адрес GitHub Pages не может быть целевым сервером.

Генерация и проверка переходов проверены на тестовом домене runtime.example.test; это не адрес развёрнутого приложения. Workflow не запускался удалённо после этих изменений. До публикации проверить доступность реального целевого сервера.

## Незавершённые интеграции

Провайдер оплаты, поставщик Steam-пополнения и коммерческий API скинов неизвестны. Пока сервер не создаёт платёж, денежное зачисление или заказ. Контракты должны определить актуальную цену/резервирование, способы оплаты, точность сумм и комиссию, создание checkout, доверенную проверку результата, идемпотентные webhook и выдачу. Возврат пользователя с платёжной страницы не является подтверждением оплаты.

Ключи только в окружении сервера. Steam OpenID ключа не требует. Существование публичного профиля проверяется на Steam Community; это не подтверждает его пригодность для пополнения у конкретного провайдера.
