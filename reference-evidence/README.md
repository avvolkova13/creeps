Кадры сохранялись после действий, с естественной задержкой; это свидетельства последовательных состояний, не видеозапись точной скорости. Наблюдалась смена цифр тёмной заставки; отдельный снимок заставки не сохранён. Read-only computed styles видимых ссылок показали `valve, "valve Fallback"`, 14 px для Years/About, 12 px для служебных ссылок, `rgb(0,0,0)` для текста.

Не проверены точные параметры анимации, hover, полный keyboard flow, шрифтовые лицензии и кириллица; просмотр viewport не равен тесту телефона. Интерпретация и предлагаемые параметры магазина отделены от наблюдений в DESIGN_DIRECTION.md.

## Другие основания проверки

- Замечание пользователя к скриншоту Eleven House: защитить подобные текстовые группы полупрозрачной подложкой. Его фон, контент и цвета не используются как новый референс.
- [W3C: Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): контраст текста 4,5:1; крупного — 3:1.
- Skill ui-ux-pro-max: прочитан; локальный поиск UX по contrast, reduced motion и labels вернул соответствующие правила. Генерация альтернативной дизайн-системы не запускалась по прямому ограничению задачи.
