## Реализация Creeps

- Множественные категории, типы, модели оружия с поиском, состояния, редкость, цвета и особенности. Между группами AND, внутри группы OR.
- Цена от/до с эквивалентом в рублях, float от/до, трейдлок у источника, наличие и поиск наклеек/брелоков.
- Индивидуальное снятие выбранных фильтров, общий сброс, количество результатов, сворачиваемые разделы и мобильная панель. Числа рядом с вариантами — количество в полном текущем ассортименте.
- Сортировка: исходный порядок, цена вверх/вниз, float по возрастанию, оценки SkinSwap по убыванию, разница цены SkinBaron и Steam по убыванию. Отсутствующие значения идут в конец, равные сохраняют исходный порядок. Собственный рекомендательный рейтинг не выдумывается.
- Все пять категорий и шесть типов берутся из текущего ассортимента. Отсутствующие типы товаров не подменяются вымышленными карточками.

## Данные и границы

68 исходных товаров сохранены. Модель оружия, тип и редкость доступны у всех 68. Цвета и оценки — у 30 товаров SkinSwap; трейдлок, сравнение со Steam и массив наклеек/брелоков — у 38 SkinBaron. Наличие поля не означает наличие наклейки. В ассортименте подтверждён один ванильный нож. Неизвестное значение не проходит фильтр по известному значению.

Характеристики извлечены из публичных `itemInfo` страниц SkinSwap и `promo-search-result-state` SkinBaron, связь — description URL / UUID предложения. Английские модели нормализованы по меню SkinBaron. Источник каждого набора указан в `attributes.evidenceUrl`. Трейдлок относится к сохранённым данным источника, не к подтверждённой выдаче в Creeps.

Даты размещения объявления и изменения его цены отсутствуют. В отдельной странице предложения SkinBaron найдены только даты снимков предмета — они не использованы как даты объявления. Поэтому «Новейшие» и «Недавнее изменение цены» пока не добавлены: нужны достоверные поля вендора. Полное совпадение всех режимов сортировки с SkinBaron этим этапом не заявляется.

`scripts/enrich_catalog.py` извлекает метаданные из `.qa/catalog-import/`; `npm run enrich:catalog` обновляет их без изменения основных полей товаров. Импорт вызывает тот же адаптер, а загрузка описаний сохраняет публичные страницы для извлечения. Недоступные исходные страницы оставляют параметры неизвестными, не создают значения по догадке.
