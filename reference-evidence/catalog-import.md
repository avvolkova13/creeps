# Временная витрина из публичных источников

Дата снимка: 2026-09-09. Источники прямо выбраны пользователем: https://skinswap.com/ru и https://skinbaron.de/ru.

Загружены 68 записей CS2: 30 SkinSwap и 38 SkinBaron. Пять категорий: ножи, винтовки, пистолеты, пистолеты-пулемёты, перчатки. Главная показывает 12 записей, каталог — все импортированные. Это выборка доступных товаров публичных главных страниц, не полная выгрузка всех каталогов сайтов. Rust не включён в текущую выборку CS2.

SkinSwap: названия, изображения, состояния, округлённый float и цены из HTML товарных карточек. SkinBaron: данные опубликованного SSR-состояния, включая отдельную цену предложения itemPrice, характеристики, коллекцию и редкость. Зачёркнутые цены Steam, скидки и рейтинги не переносятся. Float SkinBaron в процентах делится на 100; приблизительный float SkinSwap явно помечен знаком ≈.

Для всех 30 текущих записей SkinSwap подготовлены краткие русские пересказы описаний отделки с отдельных страниц скинов. Ссылки и хеш оригинала хранятся в src/data/product-descriptions.json. При обновлении пересказ применяется только при совпадении хеша исходного описания. Для предложений SkinBaron используются фактические описания из модели, состояния, редкости и коллекции, где она опубликована. Отсутствующие художественные описания не выдумываются. Чужие маркетинговые обещания, условия доставки и платежей не переносятся.

Оригинальные изображения сохранены в public/catalog без редактирования. Проверены формат файла и локальное чтение. Снимок содержит только товарные поля; идентификаторы продавцов и сессий не переносятся.

## Цены

Валютный пересчёт — по публичной таблице SkinSwap: 1 USD = 86,42 ₽, 1 EUR ≈ 100,4884 ₽ на момент снимка. Это курс источника, не курс ЦБ и не платёжное правило. Далее рубли делятся на 1,7 из projectConfig. Значения не округляются до отображения. В карточке сохранены исходные цена и валюта, дата, ссылка и курс; цены справочные. Наличие и покупка в Creeps не подтверждены.

## Обновление

`npm run import:catalog` запускает scripts/import-catalog.py (Python 3, стандартная библиотека). Нужен доступ к публичным страницам и CDN. После обновления: npm test, npm run build и перезапуск production-сервера. Автоматическое расписание не настроено.

Снимок src/data/catalog-snapshot.json заменяется атомарно после загрузки данных и изображений. При ошибке сохраняется предыдущая версия. Изображения кешируются по исходному URL. При изменении описания остаётся краткое описание по фактам до повторной редакторской проверки. Подключение будущего API отделено в src/lib/catalog-source.ts.

## Проверка

Lint, production build с TypeScript и 19 тестов прошли. Тесты проверяют все 68 локальных изображений, уникальные ID, связи с категориями, допустимые значения float, ссылки на источники, пересчёт каждой цены и сочетание фильтров на реальных записях. В браузере проверены быстрый просмотр, полная карточка, поиск Hydra, категория перчаток, ценовое ограничение, пустая выдача и сброс. Каталог и карточка: 320/390/768/1024/1440 px без overflow; мобильный диалог без переполнения. Консоль без ошибок и предупреждений.

Использован webapp-testing для проверки интерфейса через CUA. Новые агенты и пакетные зависимости не добавлены. Реальная оплата, вход, выдача, кабинет и серверный баланс не подключены.
