# Рабочий функционал Creeps — 2026-09-09

Прямое указание пользователя разрешает реализацию всех сценариев ТЗ. Утверждённые страницы, визуал и способы входа не меняются.

## Решение

Существующий Next.js запускается через Node HTTP server: UI и /api на одном origin. SQLite из Node 24 хранит серверные сессии, пользователей, корзины, операции и заказы. Новых npm-зависимостей нет. Статический экспорт GitHub Pages сохраняется для витрины; серверный функционал требует Node-хостинга с постоянным диском, HTTPS и APP_ORIGIN. Pages сам такой сервер не запускает.

1. Steam OpenID: переход на официальный домен, одноразовое состояние привязано к браузеру, проверка assertion на Steam, nonce/return_to/identity/signature, новая HttpOnly-сессия после входа, выход и отзыв сессии.
2. Кабинет: Steam ID, серверный баланс, сохранение trade-URL с проверкой владельца, пустые реальные истории без вымышленных операций.
3. Корзина: добавление с главной/карточки, удаление, сохранение на сервере, перенос гостевой корзины при входе. Позиции уникальны; цена берётся на сервере. Цена снимка не считается предложением вендора.
4. Steam-проверка: отдельный запрос по ID к Steam, ошибка связи отличается от отсутствия профиля. Проверка не подтверждает возможность пополнения конкретным провайдером.
5. Формы отправляют запросы и показывают результат конкретного действия. До получения контрактов провайдеров сервер не создаёт фиктивные платежи, начисления, заказы или выдачу.

## Необходимые внешние данные

Запрошены сервер, платёжный провайдер, провайдер прямого Steam и API вендора. Названия/контракты неизвестны, платёжные редиректы и webhook-контракты не придумываются. Без них полное выполнение платежей и доставки остаётся незавершённым.

## Проверки

Автотесты: поддельный и повторный OpenID, CSRF, истечение/выход сессии, изоляция пользователей, trade-URL, персистентность корзины, серверная цена, отказ от начисления без провайдера. UI: корзина, формы, кабинет, адаптивность, переход на Steam. Вход реальным пользователем завершается им самим на Steam. Lint, тесты, Next build, Pages export и проверка ссылок.
