# Юридический футер — рабочие тексты

Основание: пользователь попросил найти футер прежних проектов, затем разрешил временно придумать недостающую информацию для показа менеджеру.

Источник структуры: `/Users/anastasiavolkova/Documents/Сайт по продаже цифровых товаров/features/home/home-page.tsx` — три ссылки: соглашение, конфиденциальность, Cookie. В исходных документах Locker адрес не заполнен; его реквизиты не являются данными Creeps.

Использовано рабочее наименование Creeps и подтверждённый контакт support@shop-skin.com. Регистрационные номера, банковские реквизиты и адрес чужой компании не добавлялись. Тексты — редакционный материал для макета, не подтверждение юридической готовности магазина. До реальных платежей владелец должен установить оператора, юрисдикцию, адрес, правила возврата, основания/сроки обработки и состав обработчиков, затем согласовать документы.

Соглашение адаптировано к фактам ТЗ: курс 1,7 ₽, комиссия Steam 5%, отдельная корзина и выдача на trade-URL. Cookie описаны по текущей реализации; аналитические счётчики не заявлены. При изменении интеграций документы требуется обновить. Для проверки общей структуры вопросов данных просмотрен [152-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_61801/); юридическое заключение о соответствии не проводилось.

Три страницы включаются и в обычную сборку, и в GitHub Pages. Футер сохраняет утверждённые цвета, шрифты и поддержку; на мобильной ширине колонки располагаются вертикально.
