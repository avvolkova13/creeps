# Отдельная корзина — 2026-09-11

Прямое требование пользователя: корзина отдельно от личного кабинета, вход запрашивается при оформлении.

- Вынести существующие товары/итог/удаление на `/cart`, сохранить дизайн.
- Убрать корзину из кабинета и направить кнопку шапки на новый маршрут.
- Оформление гостем открывает `/login?next=cart`, без запроса создания заказа.
- После настоящего Steam-входа вернуть пользователя в `/cart`, сохранив выбор. Неподтверждённая авторизация не создаётся.
- Включить новые маршруты в Pages, проверить пустую/заполненную корзину, переход к входу и обратно, серверный callback и адаптивность. Опубликовать изменения.
